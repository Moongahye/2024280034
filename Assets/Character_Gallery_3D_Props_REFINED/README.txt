Character Room Prop Pack
=========================

What is included
- 5 standees (OBJ + MTL + PNG texture)
- 5 framed sheet boards (OBJ + MTL + PNG texture)
- 5 info stands (OBJ + MTL + PNG texture)
- 13 themed props for room dressing

Suggested room themes
1. Jiangshi room: board_jiangshi, standee_jiangshi, info_jiangshi, prop_talisman_lantern, prop_ritual_chest, prop_talisman_scroll
2. Gothic boy room: board_gothic_boy, standee_gothic_boy, info_gothic_boy, prop_chain_pedestal, prop_candle_cluster, prop_gothic_banner
3. Lilith room: board_lilith, standee_lilith, info_lilith, prop_scythe_display, prop_demon_candles, prop_demon_banner
4. Agent room: board_agent, standee_agent, info_agent, prop_company_plaque, prop_file_cabinet
5. Shark main room: board_shark, standee_shark_main, info_shark, prop_wave_pedestal, prop_shark_banner

Unity import tips
- Copy the whole folder into Assets.
- Drag OBJ files into the scene.
- If textures do not appear automatically, keep each OBJ next to its MTL and PNG.
- For standees use a transparent/cutout shader if needed.
- Recommended standee scale in Unity: start at 1,1,1. Heights are already around 1.9m ~ 2.0m.

Notes
- Standees are 2.5D exhibition props, not fully sculpted 3D characters.
- The cutout for standees was regenerated from the source sheets or transparent PNG.
