캐릭터 전시관 3D 에셋 팩 — REFINED
================================

내용
- 실루엣 형태의 2.5D 등신대 OBJ 5개 (투명 PNG 누끼 재작업)
- 사용자가 제공한 원본 시트를 적용한 벽면 액자 OBJ 5개
- 작품 앞 설명대 OBJ 5개
- 각 테마별 분위기 소품 OBJ 18개 (기존 13 + 신규 5)
- Unity Editor 프리팹 생성 도우미

Unity 설치
1. 이 Character_Gallery_3D_Props_REFINED 폴더 전체를 Unity 프로젝트 Assets 안에 복사하세요.
2. 컴파일 후 상단 Tools > Character Gallery > Build 3D Exhibit Prefabs (Refined)를 누르세요.
3. 생성된 Prefabs 폴더의 프리팹을 Scene으로 끌어 놓으세요.
4. 스탠디가 흰 사각형으로 보이면 재질의 Alpha Clipping 활성화를 확인하세요.

한계
- 등신대는 한 장의 캐릭터 그림을 실루엣 메시로 만든 2.5D 전시용 모델입니다.
- 고퀄리티 스컬프팅한 완전한 입체 캐릭터 모델은 아닙니다.
- 소품은 절차적으로 생성한 편집 가능한 로우폴리 3D입니다.
- Unity 에디터에서 실제 실행 검증을 수행한 것은 아닙니다.
- 원화 속 한글/영어와 그림은 AI로 다시 그리지 않고 업로드한 원본을 그대로 적용했습니다.
